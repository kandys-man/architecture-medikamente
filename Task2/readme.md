### Технические решения

1. **Управление доступом**:
   - Внедрение RBAC через Active Directory
   - Двухфакторная аутентификация
   - Принцип "минимальных привилегий"

2. **Мониторинг и контроль**:
   - Полное логирование операций
   - Внедрение SIEM-системы

3. **Инфраструктурные изменения**:
   - Защищенное хранилище
   - TLS-шифрование передач

## Предложения по улучшению

* Классифицировать данные на общедоступные, внутренние и конфиденциальные.

* Внедрить способы защиты для персональных данных:
    конфиденциальные - шифрование
    общедоступные - обезличивание
    внутренние - обфускация

* Внедрить использование RBAC, аутентификации и авторизации посредством использования Active Directory на всех корпоративных компьютерах.
* Разграничить доступ сотрудникам исходя из принципа наименьших привилегий "least privilege"
* Внедрить двухфакторную авторизацию с помощью мобильного телефона
* Внедрить механизмы протоколирования и контроля потока данных во внутренней сети.
* Внедрить шифрование данных при хранении и передачи
* Внедрить единую систему хранения и управления данными
* Реализовать соответствие принципам и требованиям законодательства РФ в области хранения и обработки данных
